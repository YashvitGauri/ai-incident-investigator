# AI Incident Investigator

An AI-powered incident investigation system that analyzes activity logs,
correlates events, identifies suspicious patterns, and assists with
security incident investigation.

## Goal

Build an independent, model-agnostic investigation system where the
underlying AI model can be replaced without changing the core application.

## Development

This project is being built incrementally with a focus on understanding
the architecture, implementation, testing, and engineering decisions
behind each component.
